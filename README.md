# מילים בשירים 🎵

לומדים אוצר מילים באנגלית דרך שורות משירים מוכרים. לכל מילה מוצגות שורות משירים שבהן היא מופיעה, והמילה מודגשת. לחיצה על ▶ מנגנת את הקטע בספוטיפיי.

## כתובת
האפליקציה מתארחת ב-GitHub Pages: https://shukipesso.github.io/voc-kids/

בהגדרות האפליקציה בספוטיפיי (developer.spotify.com/dashboard) צריך שיופיע ה-Redirect URI הזה בדיוק: `https://shukipesso.github.io/voc-kids/`

## הפעלה מקומית
```bash
python3 -m http.server 8888 --bind 127.0.0.1
```
פותחים את http://127.0.0.1:8888 (ב-127.0.0.1 ולא ב-localhost, כי ספוטיפיי מאשר רק את הכתובת הזאת).

## מילות השירים
האתר לא מאחסן מילים של שירים. `data/index.json` שומר רק איפה כל מילה מופיעה (מזהה השיר ב-LRCLIB וזמן השורה), והשורה עצמה נטענת מ-LRCLIB כשמציגים אותה. המילים המלאות שהסקריפטים מורידים נשמרות ב-`data/.cache`, שלא עולה לגיטהאב.

## חיבור ספוטיפיי (פעם אחת)
בעמוד ההגדרות באפליקציה יש הוראות: יוצרים אפליקציה ב-developer.spotify.com/dashboard, מגדירים בה את ה-Redirect URI ומדביקים באפליקציה את ה-Client ID.

## רשימת מילים חדשה
1. עורכים את `data/words.json` (מילה באנגלית, תרגום, `pos`: noun / verb / nounverb / adj / fixed / phrase).
2. אפשר להוסיף שירים ל-`data/songs.json`.
3. מריצים `node scripts/build-index.mjs`. הסקריפט מוריד מילים מתוזמנות מ-LRCLIB ובונה את `data/index.json`.
4. כדי למצוא שירים למילים שאין להן מספיק: `node scripts/suggest-songs.mjs candidates.json`.
5. מפרסמים עם `scripts/release.sh "תיאור השינוי"`. הסקריפט מעדכן את מספר הגרסה של הקבצים (כדי שדפדפנים לא יערבבו קבצים ישנים וחדשים), עושה commit ו-push, והאתר מתעדכן תוך דקה-שתיים.

## מבנה
- `lib/matcher.js`: זיהוי צורות של כל מילה (fell, lovin', travelled…) ומציאתן בשורות השירים. משמש גם את סקריפט הבנייה וגם את הדפדפן.
- `js/spotify.js`: התחברות לספוטיפיי (PKCE), חיפוש שירים, ניגון קטע וייבוא פלייליסטים.
- `js/app.js`: המסכים: רשימת המילים, מסך מילה, חידון והגדרות.
